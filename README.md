A timeline of Sunday 22 November 2026: the date is the headline, the capture of
FBI most-wanted kingpin "El Chapo Isidro" leads, and 24 more stories run along
a timeline from 00:00 to 24:00 UTC — overnight, morning, and afternoon &
evening — across 7 regions. Cream paper, black serif, red accents. Thumbnails
only for the hot stories; the rest are text-only.

Entry for the [make.fun bounty "Sum up 22 November's world news in one image"](https://make.fun/bounty/news-image-20261122).

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
# writes out/entry.png (1024x1024, deterministic)
```

`main.py` is standard-library only: it copies the pre-rendered `entry.png`
(shipped in this repo, drawn by `render.py`) to `$MAKEFUN_OUTPUT_DIR/entry.png`.

## The stories

**Cover — Americas.** FBI's most-wanted kingpin captured: Mexican troops seize
"El Chapo Isidro" (Fausto Isidro Meza Flores) in a Sinaloa gun battle, 11
killed. Announced 21 Nov; the story that led Sunday's news.
Sources: Reuters, CNN, Wall Street Journal.
